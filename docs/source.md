# 统计公报来源约定

目录和详情分别位于 `/catalog` 与 `/detail`，对应浏览器页面以 `.html` 结尾。详情使用目录中的稳定标识，不用显示名称做业务键。

- `edition` 为 1 或 2，表示两个发布期；
- `revision` 表示同一发布期内的发布版本，可用 `revision` 参数回读历史版本；
- `status` 为 `published` 或 `withdrawn`；撤回时正文为空，但目录条目仍可能存在；
- `coverage` 是本次发布明确覆盖的指标集合；
- `facts` 只包含有明确取值的指标，`0` 是真实零值；
- `required_coverage` 是该条目完整发布所需的指标。

采集时以详情页为准：目录状态只说明正文当前是否存在，不说明数据完整。发布期、版本和指标正文是本地演练资料中的业务语义。来源只监听环回地址，没有真实人员、订单或账号。
